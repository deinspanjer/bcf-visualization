mobile iff `(width <= 900px) OR (portrait orientation AND width <= 1100px)`.
So: 1101x900 -> desktop; 1100x900 -> ALSO desktop (landscape orientation, width > 900);
1100x1300 -> portrait (upper bound engages only in portrait); 899x900 -> portrait
(899 < 900 height means portrait orientation); 1024x768 -> desktop (iPad landscape, §7).
