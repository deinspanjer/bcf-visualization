## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → preference state | every `bcf:*` preference is user-editable and is read back into app state on load |
| app → third-party origins | outbound story links open SV / FF / AO3 in a new browsing context |
| history API → app state | `popstate` events can arrive from navigation the app did not initiate |

| T-02-11 | Tampering | Reverse tabnabbing via the three story links | medium | mitigate | Every outbound anchor carries `target="_blank"` with `rel="noopener noreferrer"`, asserted per link in `test_settings_about_help_persist_across_reload` |
| T-02-12 | Tampering | Unvalidated preference writes reaching a validated read path (`setMode`) | medium | mitigate | Add a write-side allow-list guard to `setMode` mirroring `setRollLocation`; the Settings UI additionally only offers allow-listed values, and the reload assertion proves the round trip |
