<objective>
Split the 108 genuinely curated chapters into a deterministic calibration/held-out partition
(D-21), then spend real API budget for the first time at more-than-one-chapter scale: run Stage
2 against the calibration set on BOTH claude-opus-5 and claude-sonnet-5, compare their
confidence-gate/verifier agreement, and record a data-driven model-tiering decision (D-09) that
Plan 04-05's held-out run and Phase 5's eventual bulk run will use.

Purpose: This is the "tune on calibration only" half of D-21's methodology — the held-out set
stays untouched until Plan 04-05, so the reported final numbers are never contaminated by
tuning against the same data they're measured on.
Output: `data/derived/calibration_split.json`, a committed `calibration-report.md`/`.json` pair
recording per-model calibration numbers and the tiering decision, gated by one
`checkpoint:decision` (spend approval) before any money is spent.
</objective>
