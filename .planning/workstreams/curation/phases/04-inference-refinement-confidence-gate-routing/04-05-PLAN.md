Split the genuinely-curated corpus deterministically, tune on the calibration side only, and settle
the two open parameter questions with measurements instead of assumptions: which model tier the bulk
pass should use, and whether `get_prose_span` earns its place in the tool surface.

Purpose: Phase 3 demonstrated how easily a measurement can mislead. Tuning against the set you report
on produces a number nobody can trust, so the held-out side stays sealed until 04-06.

Output: a recorded split, two comparable calibration runs, and a report whose recommendations are
each traceable to a number.
</objective>
