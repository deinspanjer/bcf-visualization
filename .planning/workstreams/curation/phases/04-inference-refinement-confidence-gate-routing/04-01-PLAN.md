## Phase Goal (derived, MVP framing)

**As** Dre, the corpus curator, **I want to** have Stage 2 pre-fill quote text, position, and
structure for each Stage 1 candidate it can support with mechanical verification and reasonable
confidence, **so that** I stop spending days manually locating and attaching evidence quotes
across the uncurated chapters — a run that hands back densely pre-filled proposals is a success
even when it auto-writes little to the trusted corpus (CONTEXT.md's value function).

format (it reads as an outcome description, not a user story) — this framing is derived
transparently from `04-CONTEXT.md`'s "value function" section rather than fabricated from
nothing. Flagged for the orchestrator/user: run `/gsd-mvp-phase 4` first if a ROADMAP-canonical

## Objective

Build and prove, end-to-end on ONE curated chapter with ONE real Anthropic API call, the full
Stage 2 spine: retrieve candidate paragraphs deterministically (D-01), prompt Claude Opus 5 with
conventions + schema + same-regime exemplars (D-05/D-07/D-08), derive quote positions
mechanically and verify with Phase 2's verifier (D-10/D-11), grade confidence compositely
(D-13), and route the result to either the trusted corpus or the proposals sidecar while never
overwriting a hand-curated chapter (CINF-04, D-15/D-17). This is the tracer that proves the
architecture before any batch machinery (Plan 04-03) or ledger (Plan 04-02) is built on top of
it.

Purpose: Establish the one sanctioned code path every later plan in this phase extends —
Batches API scale-out (04-03), idempotency (04-02), and calibration/held-out measurement
(04-04/04-05) all reuse these exact modules unmodified in their core logic.
Output: A working `python scripts/run_stage2_chapter.py --chapter <N>` that performs one real,
verified, graded, routed Stage 2 pass and a mocked-client test suite proving the deterministic
parts with zero spend.
