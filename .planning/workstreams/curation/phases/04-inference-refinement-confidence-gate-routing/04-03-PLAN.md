<objective>
Harden the confidence gate to its final D-13 TIGHTENED form and make proposal richness a structural
guarantee rather than an intention: assemble the roll object once, then route.

Purpose: this is where the phase's core value lives. The gate decides *where* output lands; it must
never decide *how much effort went into filling it in*. A run that auto-writes little but hands back
densely pre-filled chapters is a success; one that auto-writes a proud fraction and leaves the rest
blank is a failure.

Output: the four-case gate with its unit proofs, the assemble-once routing guarantee with a parity
test, and the CINF-04 never-overwrite integration tests — all driven from the recorded submission
fixture with zero inference.
</objective>
