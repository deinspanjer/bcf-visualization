<objective>
Build Stage 1: a deterministic, zero-LLM script that assembles candidate roll objects from machinery the pipeline already computes — `roll_text_evidence.json`'s anchors/prose-windows and `obtained_perks.json`'s paid-then-free bundle order — per ACUR-01 and ROADMAP success criterion 2.

For each of the 718 predicted rolls, bind: the constellation (from the bound paid perk's own `constellation` field for a hit, or from a `constellation_reveal` anchor for a miss), the paid perk that follows (from the default `merge_paid_units` bundle), the free ride-alongs in that same bundle, and — per CURATION-CONVENTIONS §2 — a liberal forward search of the chapter for each free perk's name or substring, attaching the first mention as an additional evidence quote. Any part that can't be determined is marked unfilled, never guessed (D-06).

This plan is independent of Plan 03-01 (it never touches `chapter_roll_overrides.json`) and can run in the same wave.

Purpose: measure, before Phase 4 buys any inference, how far deterministic binding alone gets — Plan 03-03 scores this plan's output against the hand-curated corpus.
Output: `scripts/build_candidate_rolls.py`, `data/derived/_schemas/candidate_rolls.schema.json`, `data/derived/candidate_rolls.json` (gitignored, regenerable), `tests/test_build_candidate_rolls.py`.
</objective>
